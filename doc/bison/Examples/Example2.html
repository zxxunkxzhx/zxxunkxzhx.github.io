lookahead sets of states

  • rules can't be reduced(as no complete items): [0..3], [8..9], [13..15], 18, [20..22], 26
  • state 4 has only one complete item(1 program → statements •), the item's lookahead set has one member, we will detail how to figure out it.
  • no lookahead set in need(as no shifts and no other reductions): [5..7], [10..12], 17, 19, [23..25], 27
  • state 9 has only one complete item and that item is empty; assume there are another item in this state which will shift, bison prefer shift; assume there are another item which can also reduce, that item's lookahead set shall conflict with this empty item's lookahead set(actually empty item's lookahead set contains everything), bison will resolve this conflict by checking which rule happens first
  • state 16: has complete items `7 uint8_hex → NUMERIC_STR •` and `8 num → NUMERIC_STR •`; will discuss later

closure(state 0)

  • state 0 has only one core `0 $accept → • program $end`, this item means on program goto some state(for here, pre-accept) and that state has an item `0 $accept → program • $end` which can shift $end then goto the special default state(accepting state)
  • decide the FIRST set propagated to `program -> • ...` items: as $end is the first symbol following program and it's a token, so FIRST($end...) is [$end]
  • `1 program → • statements, [$end]` is added
  • decide the FIRST set propagated to `statements -> • ...` items: the FIRST set propagated to these items is FIRST(ε [$end]), which is calc as [$end]
  • `2 statements → • statement, [$end]` and `3 statements → • statements statement, [$end]` are added
  • for `2 statements → • statement, [$end]`, add `4 statement → • stmt_e, [$end]` and `5 statement → • stmt_l, [$end]`, then:
    • 6 stmt_e → • FUNC_E '(' uint8_hex ',' uint8_hex ')', [$end]
    • 10 stmt_l → • FUNC_L '(' $@1 stmt_l_tail, [$end]
  • for `3 statements → • statements statement ...`, we already add `statements -> • ...` items, yet some items will be updated with FIRST(statement [$end]) into their lookahead sets:
    • `2 statements → • statement, [FUNC_E FUNC_L $end]` which means when rule 2 matched, if lookahead is FUNC_E or FUNC_L or $end, we can reduce ...
    • 4 statement → • stmt_e, [FUNC_E FUNC_L $end]
    • 5 statement → • stmt_l, [FUNC_E FUNC_L $end]
    • 6 stmt_e → • FUNC_E '(' uint8_hex ',' uint8_hex ')', [FUNC_E FUNC_L $end]
    • 10 stmt_l → • FUNC_L '(' $@1 stmt_l_tail, [FUNC_E FUNC_L $end]
