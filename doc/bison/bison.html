Introduction

Bison CAN convert an context-free grammar(CFG, any grammar expressed in a superset of BNF is a context-free grammar) into a deterministic LR parser(we name .y as parser impl file and .tab.c as parser file) employing any mode of the following:
  • LALR(1): by default we use this; LR means left-2-right
  • Canonical LR(1): Can handle all LR(1) grammars but rarely used because they can be very large
  • IELR(1): Inadequacy Elimination LR tables provide the same parsing power as canonical but tries to retain the compactness of LALR(1) tables.

any mode of LR(1) tables are deterministic, they make parsing decisions with 1(a single) lookahead token

For grammars that are ambiguous, bison can generate a GLR(generalized LR) parser which can explore multiple parse paths simultaneously and resolve ambiguity based on additional tokens; such for a parser supporting DIGIT+DIGIT+DIGIT..., if your parser did not say '+' opr is left associative or right associative but specified %glr-parser, then parser A can track (DIGIT+DIGIT)+DIGIT, while parser B can track DIGIT+(DIGIT+DIGIT)

all properly-written Yacc grammars ought to work with Bison with no change.
